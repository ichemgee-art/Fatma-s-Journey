# Fatma — Creative Content Portfolio

This is the source for Fatma's creative portfolio, reconstructed from the most recent confirmed visual references (November 2, 2026).

## Current design

- Light warm beige / cream backgrounds
- Soft purple shapes on the outer edges
- Deep navy typography with purple accents
- Hero title: **Ideas into Impact.**
- Home, Work, About, Contact navigation
- Content Plans, Voice Over, Dubbing, AI Content, Reels, Photography
- Responsive layouts, working category filters, detail dialogs and a portfolio-link copy button

## Run locally

No build tools or API credentials are needed. Open `index.html` in a web browser, or serve the repository as a static directory.

## Deploy to Vercel

1. Go to Vercel → **Add New → Project**.
2. Import `ichemgee-art/Fatma-s-Journey` from GitHub.
3. Set Framework Preset to **Other** (static HTML), with the root directory set to `./`.
4. Deploy. Vercel will produce the actual project URL.
5. Check the responsive layout and images, then share the verified link.

## Before publishing as a final personal portfolio

- Replace the representative hero photography with an approved Fatma image/asset.
- Add actual samples, audio recordings, videos, and descriptions under the six creative categories.
- Add the correct email and social media links to Contact.
- Confirm the biography wording and any experience claims. Current cards are **illustrative**, not claims of completed client projects.

The site deliberately does **not** invent client projects, email addresses or social profiles.

## Editable content

Everything is in `index.html` (HTML, CSS, and JavaScript together) for straightforward editing.
